# 02 — Быстрые отказы CI: сколько прогонов не получили машину и что под ними пряталось

Воспроизводитель к разбору на [aicoding.space](https://aicoding.space).

## Что измеряем

- Сколько прогонов GitHub Actions за период закончились **быстрым отказом**: статус `failure`, а между
  `run_started_at` и `updated_at` не больше 15 секунд. На выборке скрипт проверяет, назначался ли таким
  прогонам исполнитель.
- Сколько из быстрых отказов — прогоны с **именем-путём** (`.github/workflows/…`): так в данных выглядят
  прогоны конвейера, чей файл GitHub не разобрал. Скрипт печатает их по точному имени файла, с первым и
  последним временем.
- Расчётную стоимость по прейскуранту (не счёт) по месяцам.
- Что меняли вершины коммитов, у которых были задания с расчётной стоимостью: только документы, код или
  инструменты.

## Как повторить

Нужны Python 3, `gh` с доступом на чтение Actions, git и локальная история репозитория.

```bash
python3 ci-cost.py OWNER/REPO --since 2026-07-01 --until 2026-09-27 --out ci-data
python3 push-kinds.py --data ci-data --since 2026-09-19
python3 push-kinds.py --data ci-data --since 2026-09-19 --range-from-previous
```

`--offline` пересчитывает по уже выгруженным `ci-data/runs.jsonl.gz` и `jobs.jsonl.gz`, не обращаясь к API.

## Наши выводы (данные приватного репозитория не публикуются, только результаты)

- `ci-cost-offline-2026-07-01..09-27.txt` — месяцы, прогоны с именем-путём, все дни;
- `live-check-2026-09-26..27.txt` — сетевой прогон на двух днях с проверкой правила на выборке;
- `push-kinds-parent.txt`, `push-kinds-previous.txt` — два способа разделения вершин;
- `os-matrix-history.txt`, `fix-commit-e8f91f73a.txt`, `os-matrix-normal-name.txt` — история файла
  конвейера, который 23 дня не запускался, и первый прогон под собственным именем.

## Пределы

- Стоимость — по прейскуранту стандартных исполнителей до вычета бесплатной квоты, не выставленный счёт.
- Сборщик не извлекает диагностику каждого отказа; причины групп сопоставлены с датами и историей git.
- Проверка «исполнитель не назначался» — выборочная и только в сетевом режиме. Если она находит
  исполнителей, пересчитать нужно и число, и стоимость: задания быстрых отказов в расчёт не включаются.
- Разделение вершин на «документы» и «код» зависит от способа подсчёта и шаблонов путей.
