# 03 — Тест проверял строку в .gitignore, а не то, что git игнорирует файл

Воспроизводитель к разбору на [aicoding.space](https://aicoding.space).

## Что показывает скрипт

`gitignore-anchor.sh` создаёт временный репозиторий и в четырёх положениях сравнивает два теста одной
защиты «журнал не попадает в git»:

- **строковый тест** — в `.gitignore` есть строка `.dz/usage.jsonl`;
- **тест через git** — `git check-ignore -q <путь>` для реально записанного файла.

Шаблон со слэшем в начале или середине git сопоставляет относительно каталога самого `.gitignore`, поэтому
`.dz/usage.jsonl` в корне не игнорирует `packages/mypkg/.dz/usage.jsonl`. Строковый тест ошибается в обе
стороны: зелёный, когда вложенный журнал не игнорируется, и красный после исправления на
`**/.dz/usage.jsonl`. Тест через git во всех четырёх положениях отвечает верно.

## Как повторить

```bash
bash gitignore-anchor.sh
```

Нужен только git. Скрипт работает во временном каталоге и удаляет его. Наш вывод — `gitignore-anchor.out.txt`
(git 2.34.1).

## Пределы

- `.gitignore` действует только на неотслеживаемые файлы: уже добавленный в индекс файл игнорирование не
  спасает. Тест через git отвечает на вопрос «игнорируется ли», а не «никогда не попадёт в коммит».
- Один случай из нашего репозитория; частоту таких тестов в других проектах мы не измеряли.
