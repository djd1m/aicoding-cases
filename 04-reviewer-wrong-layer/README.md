# 04 — Находка ревьюера: проверьте её на нужном слое

Воспроизводитель к разбору на [aicoding.space](https://aicoding.space).

## Что здесь

- `finding-layers.sh` — два приёма проверки находки ревьюера:
  - `file` — строки файла на двух ревизиях с настоящими номерами и число вхождений строки (`NEEDLE`) в файле на
    каждой ревизии и в диффе между ними. Ноль в диффе при вхождении в файле на обеих ревизиях значит: строка была до
    правки, а ревьюер, видевший только дифф, её не видел.
  - `gen` — число вхождений буквальной подстроки в исходнике и в выводе команды генерации.
  Любая ошибка (нет ревизии, нет файла, упала команда) — код 1 и никаких чисел.
- `case1-temp-root.txt` — записанный вывод на нашем случае 1 (ревизии нашего приватного репозитория).
- `qe-excerpts.md` — выдержки из отчётов проверки с четырьмя разобранными находками.

## Как повторить на своей находке

```bash
NEEDLE='<строка, которой по мнению ревьюера нет>' bash finding-layers.sh file <путь> <от>,<до> <база> [после]
bash finding-layers.sh gen <исходник> '<подстрока>' '<команда генерации>'
```

Нужны git и bash.

## Пределы

- Четыре случая одного репозитория; доля ошибочных находок не оценивается.
- «Не тот слой» — наша классификация трёх случаев, не измеренная закономерность.
