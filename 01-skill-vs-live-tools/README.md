# 01 — Навык описывает инструменты MCP-сервера: сверьте его с живым `tools/list`

Воспроизводитель к разбору на [aicoding.space](https://aicoding.space).

## Что проверяем

Навык (Skill, папка с `SKILL.md`) — это знание: как делать. MCP-сервер — это доступ: какие инструменты
реально можно вызвать. Когда навык перечисляет инструменты сервера по памяти, а не по ответу сервера,
агент, следующий навыку, зовёт инструменты, которых нет.

Скрипт делает одно измерение: выписывает из `SKILL.md` имена инструментов (идентификаторы
`snake_case` в обратных кавычках и в ячейках таблиц), поднимает сервер, спрашивает у него по stdio
`initialize` и `tools/list` (все страницы ответа) и печатает пересечение. Ошибка сервера даёт код выхода 4,
отсутствие ответа за 300 с — код 3, ошибка вызова — код 2, список длиннее 100 страниц (не дочитан) — код 5.

## Как повторить на своём навыке (30–60 минут)

Нужен Node.js 18+. Зависимостей у скрипта нет.

```bash
node skill-vs-server.mjs <путь к SKILL.md> -- <команда запуска сервера> [аргументы...]
```

Переменная `TOOL_PREFIX` оставляет только имена с этим префиксом — полезно, если в документе много
других идентификаторов. Базу сервера направьте во временный файл, чтобы не трогать рабочую.

## Наш случай — точные команды

```bash
npm pack @dzhechkov/skills-mcp@0.3.6 && tar xzf dzhechkov-skills-mcp-0.3.6.tgz
npm i agentdb@3.0.0-alpha.20            # первая установка качается несколько минут
AGENTDB_PATH=/tmp/case-agentdb.db TOOL_PREFIX=agentdb_ \
  node skill-vs-server.mjs package/agentdb-memory/SKILL.md -- npx --no-install agentdb mcp start
```

Ожидаемый вывод записан в `expected-0.3.6.txt`: в навыке 26 имён, у сервера 35 инструментов,
существуют 3, не существуют 23. На `@dzhechkov/skills-mcp@0.3.11` команда запускается БЕЗ `TOOL_PREFIX`
(в исправленном навыке есть имена без префикса) и даёт 35 из 35 — `expected-0.3.11.txt`.

Остальные файлы папки:
- `versions-vs-alpha20.txt` — все 12 версий пакета с этим навыком (0.2.0–0.3.11) против сервера alpha.20, полные списки;
- `sets-identical.txt` — наборы отсутствующих имён совпадают во всех девяти версиях до исправления;
- `expected-0.2.0-vs-alpha16.txt` — самая ранняя версия с навыком против сервера, последнего на дату её публикации;
- `prefix-analysis.txt` — сколько из 23 отсутствующих имён совпадают с живыми после снятия префикса `agentdb_` (4);
  для остальных 19 другие сопоставления не проверялись;
- `files-0.1.0.txt` — состав версии 0.1.0 (навыка в ней ещё нет);
- `npm-time-*.json` — даты публикации версий обоих пакетов из реестра npm.

Сервер печатает на stdout баннер до JSON-RPC; скрипт пропускает строки, которые не разбираются как JSON.

## Что это измерение НЕ доказывает

- Это один навык и один сервер (n = 1).
- Скрипт ищет имена по форме `snake_case`. Идентификатор, который не является инструментом, попадёт в
  «не существуют» — такие строки надо отсеять глазами или префиксом.
- Совпадение сегодня не гарантирует совпадение завтра: сервер, установленный по плавающей метке
  (`@latest`), меняет список без предупреждения. Ловить это может только регулярная проверка против живого
  сервера, а не модульный тест без сети.
